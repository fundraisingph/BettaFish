# BettaFish - Multi-Agent Public Opinion Analysis System

## Project Overview

BettaFish (微舆) is an innovative multi-agent public opinion analysis system built from scratch. It helps users break through information cocoons, restore the true appearance of public opinion, predict future trends, and assist in decision-making. Users simply need to ask analysis questions like chatting, and the agents will automatically analyze 30+ mainstream domestic and international social media platforms and millions of public comments.

The name "微舆" (Wēi Yú) is a homophone for "微鱼" (tiny fish), BettaFish is a small but very aggressive and beautiful fish, symbolizing "small but powerful, not afraid of challenges".

## Core Value Proposition

The platform addresses the need for easy-to-use, customizable public opinion analysis by providing:

- **Simplicity**: User-friendly interface for public opinion analysis without extensive coding
- **OpenAI Integration**: Direct integration with OpenAI's powerful Assistant API
- **Customization**: Extensive UI and behavior customization options
- **Multi-tenancy**: Secure isolation for different users and organizations
- **Open Source**: Full codebase available for community contributions and self-hosting

## Target Users

The platform serves multiple user segments:
- **Small Businesses**: Need for customer support automation
- **Developers**: Looking to integrate AI chatbots into applications
- **Content Creators**: Want to add interactive elements to websites
- **Enterprise Teams**: Require customizable AI solutions with data privacy
- **Agencies**: Building chatbot solutions for multiple clients

## Key Differentiators

1. **Multi-Agent Architecture**: Specialized agents for different analysis tasks (Insight, Media, Query, Report)
2. **Forum Collaboration**: Agent "forum" mechanism for collective intelligence and decision support
3. **Comprehensive Data Sources**: Integration with 30+ social media platforms and web search
4. **Advanced Analysis**: Beyond LLM with fine-tuned models and statistical middleware
5. **Multimodal Capabilities**: Analysis of text, images, videos, and structured data
6. **Open Source**: Complete transparency and customization capabilities

## Business Model

- **Free Tier**: Basic features with limited chatbots and messages
- **Professional Tier**: Advanced features with higher limits
- **Enterprise Tier**: Full feature set with unlimited usage and support

## Technical Philosophy

Built on modern Python architecture with:
- Multi-agent system design with specialized capabilities
- PostgreSQL database with SQLAlchemy ORM
- OpenAI API integration for AI functionality
- Flask web framework with real-time communication
- Component-based architecture with modular design
- Docker containerization for easy deployment
