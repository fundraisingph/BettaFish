# Contributing Guide

Thank you for your willingness to contribute to this project!
To maintain code quality and clear version management, please follow the steps below to submit your modifications.

# 🪄 Pull Request (PR) Submission Steps

## 1️⃣ Fork Repository

Fork this repository to your GitHub account.

## 2️⃣ Clone to Local

```bash
git clone https://github.com/<your-username>/<repository-name>.git
cd <repository-name>
```

## 3️⃣ Create Feature Branch

```bash
git checkout -b feature/your-feature-name
```

> Recommended branch naming convention: `feature/xxx` or `fix/xxx` to easily identify feature or fix types.

## 4️⃣ Development and Testing

* Make code modifications while maintaining consistent project code style.
* Ensure new features or fixes pass tests.

## 5️⃣ Submit Changes

```bash
git add .
git commit -m "type: brief description"
```

> Recommended to follow [Conventional Commits](https://www.conventionalcommits.org/en/) to maintain clear commit records.

## 6️⃣ Push to Remote Repository

```bash
git push origin feature/your-feature-name
```

## 7️⃣ Create Pull Request

1. Click **New Pull Request** on GitHub.
2. **The target branch must be the `main` branch of this repository**.
3. Fill in PR description:

   * Describe main changes
   * If there are related issues, please link them in the PR
