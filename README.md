## ⚡ Project Overview

"**BettaFish**" is an innovative multi-agent public opinion analysis system built from scratch, helping everyone break through information cocoons, restore the true appearance of public opinion, predict future trends, and assist in decision-making. Users only need to ask analysis questions like chatting, and the agents will automatically analyze 30+ mainstream domestic and international social media platforms and millions of public comments.

> "BettaFish" is a homophone for "tiny fish", BettaFish is a small but very aggressive and beautiful fish, symbolizing "small but powerful, not afraid of challenges"

View the system with "Wuhan University Public Opinion" as an example, generating research reports: [Wuhan University Brand Reputation Deep Analysis Report](./final_reports/final_report__20250827_131630.html)

View the system with "Wuhan University Public Opinion" as an example, a complete operation video: [Video - Wuhan University Brand Reputation Deep Analysis Report](https://www.bilibili.com/video/BV1TH1WBxEWN/?vd_source=da3512187e242ce17dceee4c537ec7a6#reply279744466833)

Not only reflected in report quality, compared to similar products, we have 🚀 six major advantages:

1. **AI-driven Global Monitoring**: AI crawler cluster operates 24/7, comprehensively covering 10+ key domestic and international social media platforms such as Weibo, Xiaohongshu, Douyin, Kuaishou, etc. Not only captures hot content in real-time, but also drills down to massive user comments, letting you hear the most authentic and widespread public voices.

2. **Composite Analysis Engine Beyond LLM**: We not only rely on 5 professionally designed Agents, but also integrate fine-tuned models, statistical models and other middleware. Through multi-model collaborative work, we ensure the depth, accuracy and multi-dimensional perspective of analysis results.

3. **Powerful Multimodal Capabilities**: Break through text-image limitations, can deeply parse short video content such as Douyin, Kuaishou, etc., and accurately extract structured multimodal information cards like weather, calendar, stock quotes from modern search engines, allowing you to fully grasp public opinion dynamics.

4. **Agent "Forum" Collaboration Mechanism**: Different Agents are endowed with unique toolsets and thinking patterns, introducing a debate host model, conducting chain-style thinking collisions and debates through the "forum" mechanism. This not only avoids the thinking limitations and homogenization caused by single model communication, but also stimulates higher-quality collective intelligence and decision support.

5. **Seamless Integration of Public and Private Data**: The platform not only analyzes public opinion, but also provides high-security interfaces, supporting you to seamlessly integrate internal business databases with public opinion data. Breaking down data barriers, providing powerful analysis capabilities of "external trends + internal insights" for vertical businesses.

6. **Lightweight and Highly Extensible Framework**: Based on pure Python modular design, achieving lightweight, one-click deployment. Clear code structure allows developers to easily integrate custom models and business logic, enabling rapid platform extension and deep customization.

**Starting with Public Opinion, Not Limited to Public Opinion**. The goal of "BettaFish" is to become a concise and universal data analysis engine that drives all business scenarios.

## 🏗️ System Architecture

### 整体架构图

**Insight Agent** Private Database Mining: Private public opinion database deep analysis AI agent

**Media Agent** Multimodal Content Analysis: AI agent with powerful multimodal capabilities

**Query Agent** Precise Information Search: AI agent with domestic and international web search capabilities

**Report Agent** Intelligent Report Generation: Multi-round report generation AI agent with built-in templates

### Complete Analysis Process

| 步骤 | 阶段名称 | 主要操作 | 参与组件 | 循环特性 |
|------|----------|----------|----------|----------|
| 1 | 用户提问 | Flask主应用接收查询 | Flask主应用 | - |
| 2 | 并行启动 | 三个Agent同时开始工作 | Query Agent、Media Agent、Insight Agent | - |
| 3 | 初步分析 | 各Agent使用专属工具进行概览搜索 | 各Agent + 专属工具集 | - |
| 4 | 策略制定 | 基于初步结果制定分块研究策略 | 各Agent内部决策模块 | - |
| 5-N | **循环阶段** | **论坛协作 + 深度研究** | **ForumEngine + 所有Agent** | **多轮循环** |
| 5.1 | 深度研究 | 各Agent基于论坛主持人引导进行专项搜索 | 各Agent + 反思机制 + 论坛引导 | 每轮循环 |
| 5.2 | 论坛协作 | ForumEngine监控Agent发言并生成主持人引导 | ForumEngine + LLM主持人 | 每轮循环 |
| 5.3 | 交流融合 | 各Agent根据讨论调整研究方向 | 各Agent + forum_reader工具 | 每轮循环 |
| N+1 | 结果整合 | Report Agent收集所有分析结果和论坛内容 | Report Agent | - |
| N+2 | IR中间表示 | 动态选择模板和样式，多轮生成元数据，装订为IR中间表示 | Report Agent + 模板引擎 | - |
| N+3 | 报告生成 | 分块进行质量检测，基于IR渲染成交互式 HTML 报告 | Report Agent + 装订引擎 | - |

## 🚀 Quick Start

You have two options for development: Docker-based or no-Docker setup.

### Option 1: Docker Setup (Recommended)

1. **Clone and Setup**:
   ```bash
   git clone <repository-url>
   cd BettaFish
   ```

2. **Set up environment variables**:
   ```bash
   cp .env.example .env
   # Edit .env with your configuration
   ```

3. **Start Development Environment**:
   ```bash
   ./scripts/dev-start.sh
   ```

4. **Access the application**:
   - Frontend: http://localhost:3000
   - Backend API: http://localhost:8000
   - API Documentation: http://localhost:8000/docs

### Option 2: No-Docker Setup (For advanced users)

1. **Install prerequisites**:
   - PostgreSQL 13+ running on localhost:5432
   - Redis 6+ running on localhost:6379
   - Python 3.9+
   - Node.js 18+

2. **Clone and Setup**:
   ```bash
   git clone <repository-url>
   cd BettaFish
   ```

3. **Set up environment variables**:
   ```bash
   cp .env.example .env
   cp frontend/.env.local.example frontend/.env.local
   # Edit both files with your configuration and local database settings
   ```

4. **Start Development Environment**:
   ```bash
   ./scripts/dev-start-no-docker.sh
   ```

5. **Verify Setup (Optional)**:
   ```bash
   ./scripts/test-no-docker-setup.sh
   ```

6. **Access the application**:
   - Frontend: http://localhost:3000
   - Backend API: http://localhost:8000
   - API Documentation: http://localhost:8000/docs

7. **Stop Development Environment**:
   ```bash
   ./scripts/dev-stop.sh
   ```

## ⚡ Project Overview

"**BettaFish**" is an innovative multi-agent public opinion analysis system built from scratch, helping everyone break through information cocoons, restore the true appearance of public opinion, predict future trends, and assist in decision-making. Users only need to ask analysis questions like chatting, and the agents will automatically analyze 30+ mainstream domestic and international social media platforms and millions of public comments.

> "BettaFish" is a homophone for "tiny fish", BettaFish is a small but very aggressive and beautiful fish, symbolizing "small but powerful, not afraid of challenges"

View the system with "Wuhan University Public Opinion" as an example, generating research reports: [Wuhan University Brand Reputation Deep Analysis Report](./final_reports/final_report__20250827_131630.html)

View the system with "Wuhan University Public Opinion" as an example, a complete operation video: [Video - Wuhan University Brand Reputation Deep Analysis Report](https://www.bilibili.com/video/BV1TH1WBxEWN/?vd_source=da3512187e242ce17dceee4c537ec7a6#reply279744466833)

Not only reflected in report quality, compared to similar products, we have 🚀 six major advantages:

1. **AI-driven Global Monitoring**: AI crawler cluster operates 24/7, comprehensively covering 10+ key domestic and international social media platforms such as Weibo, Xiaohongshu, Douyin, Kuaishou, etc. Not only captures hot content in real-time, but also drills down to massive user comments, letting you hear the most authentic and widespread public voices.

2. **Composite Analysis Engine Beyond LLM**: We not only rely on 5 professionally designed Agents, but also integrate fine-tuned models, statistical models and other middleware. Through multi-model collaborative work, we ensure the depth, accuracy and multi-dimensional perspective of analysis results.

3. **Powerful Multimodal Capabilities**: Break through text-image limitations, can deeply parse short video content such as Douyin, Kuaishou, etc., and accurately extract structured multimodal information cards like weather, calendar, stock quotes from modern search engines, allowing you to fully grasp public opinion dynamics.

4. **Agent "Forum" Collaboration Mechanism**: Different Agents are endowed with unique toolsets and thinking patterns, introducing a debate host model, conducting chain-style thinking collisions and debates through the "forum" mechanism. This not only avoids the thinking limitations and homogenization caused by single model communication, but also stimulates higher-quality collective intelligence and decision support.

5. **Seamless Integration of Public and Private Data**: The platform not only analyzes public opinion, but also provides high-security interfaces, supporting you to seamlessly integrate internal business databases with public opinion data. Breaking down data barriers, providing powerful analysis capabilities of "external trends + internal insights" for vertical businesses.

6. **Lightweight and Highly Extensible Framework**: Based on pure Python modular design, achieving lightweight, one-click deployment. Clear code structure allows developers to easily integrate custom models and business logic, enabling rapid platform extension and deep customization.

**Starting with Public Opinion, Not Limited to Public Opinion**. The goal of "BettaFish" is to become a concise and universal data analysis engine that drives all business scenarios.

## 🏗️ System Architecture

### 整体架构图

**Insight Agent** Private Database Mining: Private public opinion database deep analysis AI agent

**Media Agent** Multimodal Content Analysis: AI agent with powerful multimodal capabilities

**Query Agent** Precise Information Search: AI agent with domestic and international web search capabilities

**Report Agent** Intelligent Report Generation: Multi-round report generation AI agent with built-in templates

### Complete Analysis Process

| 步骤 | 阶段名称 | 主要操作 | 参与组件 | 循环特性 |
|------|----------|----------|----------|----------|
| 1 | 用户提问 | Flask主应用接收查询 | Flask主应用 | - |
| 2 | 并行启动 | 三个Agent同时开始工作 | Query Agent、Media Agent、Insight Agent | - |
| 3 | 初步分析 | 各Agent使用专属工具进行概览搜索 | 各Agent + 专属工具集 | - |
| 4 | 策略制定 | 基于初步结果制定分块研究策略 | 各Agent内部决策模块 | - |
| 5-N | **循环阶段** | **论坛协作 + 深度研究** | **ForumEngine + 所有Agent** | **多轮循环** |
| 5.1 | 深度研究 | 各Agent基于论坛主持人引导进行专项搜索 | 各Agent + 反思机制 + 论坛引导 | 每轮循环 |
| 5.2 | 论坛协作 | ForumEngine监控Agent发言并生成主持人引导 | ForumEngine + LLM主持人 | 每轮循环 |
| 5.3 | 交流融合 | 各Agent根据讨论调整研究方向 | 各Agent + forum_reader工具 | 每轮循环 |
| N+1 | 结果整合 | Report Agent收集所有分析结果和论坛内容 | Report Agent | - |
| N+2 | IR中间表示 | 动态选择模板和样式，多轮生成元数据，装订为IR中间表示 | Report Agent + 模板引擎 | - |
| N+3 | 报告生成 | 分块进行质量检测，基于IR渲染成交互式 HTML 报告 | Report Agent + 装订引擎 | - |

## 🚀 Quick Start (Docker)

### 1. Start Project

Copy a `.env.example` file, rename it to `.env`, and configure the environment variables in the `.env` file as needed

Execute the following command to start all services in the background:

```bash
docker compose up -d
```

> **Note: Image pulling may be slow**, in the original `docker-compose.yml` file, we have provided backup mirror addresses through **comments** for you to replace

### 2. Configuration Instructions

#### Database Configuration (PostgreSQL)

请按照以下参数配置数据库连接信息，也支持Mysql可自行修改：

| 配置项 | 填写值 | 说明 |
| :--- | :--- | :--- |
| `DB_HOST` | `db` | 数据库服务名称 (对应 `docker-compose.yml` 中的服务名) |
| `DB_PORT` | `5432` | 默认 PostgreSQL 端口 |
| `DB_USER` | `bettafish` | 数据库用户名 |
| `DB_PASSWORD` | `bettafish` | 数据库密码 |
| `DB_NAME` | `bettafish` | 数据库名称 |
| **其他** | **保持默认** | 数据库连接池等其他参数请保持默认设置。 |

#### Large Model Configuration

> All our LLM calls use OpenAI's API interface standard

After completing database configuration, please properly configure **all large model related parameters** to ensure the system can connect to your selected large model service.

#### 6.4 Command Line Report Generation Tool

This tool will skip the three analysis engine running phases, directly read their latest log files, and generate comprehensive reports without Web interface (while omitting file incremental validation steps). Usually used for scenarios where report generation results are unsatisfactory and need quick retry, or when debugging Report Engine.

```bash
# Basic usage (automatically extract topic from filename)
python report_engine_only.py

# Specify report topic
python report_engine_only.py --query "Civil Engineering Industry Analysis"

# Skip PDF generation (even if system supports)
python report_engine_only.py --skip-pdf

# Show detailed logs
python report_engine_only.py --verbose

# View help information
python report_engine_only.py --help
```

**Feature Description:**

1. **Automatic Dependency Check**: Program automatically checks system dependencies required for PDF generation, will give installation prompts if missing
2. **Get Latest Files**: Automatically get latest analysis reports from three engine directories (`insight_engine_streamlit_reports`, `media_engine_streamlit_reports`, `query_engine_streamlit_reports`)
3. **File Confirmation**: Display all selected file names, paths and modification times, wait for user confirmation (default input `y` to continue, input `n` to exit)
4. **Direct Report Generation**: Skip file addition review program, directly call Report Engine to generate comprehensive reports
5. **Automatic File Saving**:
   - HTML reports saved to `final_reports/` directory
   - PDF reports (if dependencies available) saved to `final_reports/pdf/` directory
   - File naming format: `final_report_{topic}_{timestamp}.html/pdf`

**Notes:**

- Ensure at least one of the three engine directories contains `.md` report files
- Command line tools and Web interface are mutually independent, will not affect each other
- PDF generation requires installing system dependencies, see above "Install System Dependencies Required for PDF Export" section
